SCEMQ v0.6.0 — Cutscenes, Perspective & Playability

Cumulative release over v0.5.5.

CUTSCENES AND SEQUENCING
- Rule actions now run as a real script. New actions: wait, moveCharacterTo,
  faceCharacter, cameraPanTo, cameraFollowPlayer, setInputEnabled, fadeOut,
  fadeIn, playSound, playMusic, stopMusic, switchPlayerCharacter, stopDialogue.
- moveCharacterTo walks ANY character, not just the player, using the scene's
  walk areas for pathfinding. NPCs can finally move.
- Awaitable actions (say, wait, moveCharacterTo, cameraPanTo, playAnimation,
  fadeOut, fadeIn) hold the sequence until they finish. Looping animations
  never block.
- setInputEnabled locks and returns player control for staged scenes.

SPEECH
- Lines float above the speaker in that character's own colour instead of
  overwriting a single status string. Two characters can talk at once.
- Hold time scales with line length, with a floor and a ceiling. Text speed and
  the default colour are project settings; per-character colour lives on the
  character.
- Clicking a line dismisses it early.

PERSPECTIVE
- Scale areas: a polygon with a top and bottom scale. A character standing at
  the back of the polygon renders small and grows as they walk forward, with
  the feet anchor pinned. Drawn in the Visual editor beside walk and depth areas.

AUDIO
- Persistent audio engine with music, ambient and sfx channels and volume
  settings. Music no longer restarts on a scene change when both scenes use the
  same track; different tracks crossfade. playSound fires one-shot effects
  registered per scene.

PLAYABILITY CHECK (new project panel)
- Reads every scene and follows the puzzle graph: unobtainable items, flags that
  are tested but never set, exits gated behind conditions nothing can satisfy,
  scenes no exit or changeScene reaches, dialogue nodes with no route in, rules
  pointing at deleted objects, and story-critical items a rule can consume.
- Items can be marked story-critical in the Inventory panel.

TEXT & TRANSLATION (new project panel)
- Every authored string is collected under a stable key into
  project/project.strings.json: dialogue beats and choices, say actions, hotspot
  labels, item names and descriptions, blocked-exit messages, GUI button labels,
  title screen text.
- CSV export and import for translators. Rescanning never discards existing
  translations; it flags rows whose source text changed.
- Pick the runtime language in Settings. Untranslated lines fall back to source.

INPUT AND UX
- Right-click fires a configurable verb (Look by default). Keyboard verb
  shortcuts: W L U T P G O C S Y.
- Project-level default verb responses in the player character's voice, with
  multiple lines picked at random, replacing the flat "Nothing happens."
- Save/load panel with named slots, scene name, timestamp and playtime, plus
  autosave on scene change. Old saves are migrated, not rejected.
- Dialogue choices can be marked "ask only once" and disappear after use.

CHARACTERS
- switchPlayerCharacter hands control to another playable character. Inventory
  can be shared across characters or kept per character (Day of the Tentacle
  structure) via a Settings toggle.

COMPATIBILITY
- v0.5.5 projects load unchanged. New settings, scale areas and the string table
  are created with defaults on first load; project.strings.json is added
  automatically.
- All earlier systems remain: Scene Manager, camera zoom, sprite-strip
  animation, title screens, portable scene packages, alpha hotspots.
